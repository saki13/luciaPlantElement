# 植物立绘工坊 · 使用说明

这是一个**离线**的立绘工作台：双击 `index.html` 就能用，不联网（除非你自己开生成），
内置了游戏现有的 51 个角色（36 株植物 + 15 种僵尸）。

## 一、五分钟快速上手

```
① 双击 index.html
② 左边选一个角色（或「＋新建植物」）
③ 点中间任意一格 → 上方出现这一帧的 prompt，可以改
④ 点「导出生成任务 .zip」→ 得到 xxx_jobs.zip
⑤ 双击「开始生成」脚本（Windows: 开始生成.bat / Mac: 开始生成.command）
⑥ 得到 xxx_results.zip → 回网页点「导入生成结果」
⑦ 重复 ③~⑥，直到满意
⑧ 点「导出工作副本」留着，再点「导出全部已改」发回给开发
```

> **为什么不能直接在网页里生成？**
> ModelScope 服务端不允许浏览器直连（CORS），网页里发请求一定失败。
> 所以生成这一步交给我们提供的 Python 脚本，其它都在网页里完成。

## 二、第一步：安装 Python

脚本只用到 Python 标准库，**不需要 `pip install` 任何东西**。

### macOS

**方式 A：官网安装包（推荐，最简单）**

1. 打开 <https://www.python.org/downloads/macos/>
2. 点第一个 **Download Python 3.x.x** 按钮
3. 双击下载的 `.pkg`，一路「继续」→「同意」→「安装」
4. 装完后，打开「终端」（Launchpad 里搜 `终端` 或 `Terminal`），输入：

   ```bash
   python3 --version
   ```

   看到 `Python 3.x.x` 就成功了。

> ⚠️ **不要**用 `sudo` 安装任何东西，也不需要。
> 如果 `python3` 提示 `command not found`，说明安装包没装好，重装一次。

**方式 B：用 Homebrew（如果你已经在用 brew）**

```bash
brew install python
```

**方式 C：如果装完 `python3` 仍然不存在**

macOS 会弹窗提示「需要安装命令行开发者工具」，点「安装」等它装完即可。

### Windows

1. 打开 <https://www.python.org/downloads/windows/>
2. 下载 **Windows installer (64-bit)**
3. 运行安装包，**务必勾选最下面的 `Add python.exe to PATH`**
4. 点 **Install Now**
5. 安装完成后，按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入：

   ```bat
   python --version
   ```

   看到 `Python 3.x.x` 就成功了。

> 如果提示 `'python' 不是内部或外部命令`，说明第 3 步没勾上。
> 重新运行安装包，选 **Modify** → 勾上 `Add python.exe to PATH` 再装一次。

## 三、第二步：拿 ModelScope 令牌

1. 打开 <https://modelscope.cn> 并登录（没有账号就注册）
2. 右上角头像 → **个人中心** → 左侧 **访问令牌**（Access Token）
3. 点「新建令牌」或复制已有的，形如 `ms-xxxxxxxx-xxxx-xxxx`
4. **这是一串密钥，不要发到群里、不要提交到代码仓库**

> 这是别人给你开通的账号，如果拿不到令牌，直接找对接的开发要。

## 四、第三步：把令牌告诉脚本

令牌**不能写进脚本**，用「环境变量」传给它。二选一：

### macOS（在「终端」里执行一次）

```bash
export MODELSCOPE_TOKEN="ms-你复制的令牌"
```

> 这样只对当前这个终端窗口有效。关掉窗口就要再设一次。
> 想永久生效：

```bash
echo 'export MODELSCOPE_TOKEN="ms-你复制的令牌"' >> ~/.zshrc
source ~/.zshrc
```

### Windows（PowerShell 里执行一次）

```powershell
$env:MODELSCOPE_TOKEN = "ms-你复制的令牌"
```

> 只对当前 PowerShell 窗口有效。想永久生效：

```powershell
setx MODELSCOPE_TOKEN "ms-你复制的令牌"
```

（`setx` 之后要**重新打开**一个新的窗口才生效。）

### 更省事的办法：用一个 `.token` 文件

在工坊文件夹里新建一个**纯文本**文件，文件名就叫 `.token`，
内容只有一行令牌（不要有空格和换行以外的字符）：

```
ms-你复制的令牌
```

macOS 的 `开始生成.command` 会自动读取它。Windows 用户建议还是用环境变量。

## 五、第四步：生成图片

### 方法 A：双击（最简单）

| 系统 | 文件 |
|---|---|
| Windows | `开始生成.bat` |
| macOS | `开始生成.command` |

脚本会自动找同目录下的 `*_jobs.zip`。

### 方法 B：命令行（更灵活）

```bash
# 先看计划，不花额度
python3 art_studio_cli.py 你的任务包.zip --dry-run

# 真的生成
python3 art_studio_cli.py 你的任务包.zip

# 只重跑某几帧
python3 art_studio_cli.py 你的任务包.zip --only idle_0,attack_1
```

Windows 把 `python3` 换成 `python`。

跑完会得到 `xxx_results.zip`，里面是 `<角色key>__<帧名>.png`。

> **耗时参考**：一帧通常 20~60 秒。11 帧大约 5~10 分钟。
> 中途按 `Ctrl + C` 可以停，已经生成的部分仍然会保存。

## 六、第五步：导回网页

回到页面，点右下的 **「导入生成结果 .zip」**，选中 `xxx_results.zip`。

会按文件名里的 `<key>__<slot>` 自动回填到对应的格子，日志区会显示「已导入 N 帧」。

## 七、怎么保存进度

| 方式 | 说明 |
|---|---|
| **导出工作副本** ⭐ | 下载一个新的 HTML，里面含你改过的全部图和每帧 prompt。**下次双击那个新文件就接着改**。不依赖浏览器存储，Mac 上也没问题 |
| 自动保存 | Chrome / Edge 会自动存到本机浏览器（左上角显示「已保存到本机 HH:MM」）；Safari 双击打开时浏览器会禁用存储，只靠上面那条 |
| 导出全部已改 | 发给开发：所有改过的角色的精灵表 + `workspace.json` |

**建议习惯**：改完一批就点一次「导出工作副本」，文件名自带时间，等于自动版本管理。

## 八、帧规格

| 项 | 要求 |
|---|---|
| 一帧一张图 | 尺寸不限，页面会自动缩放并底部居中 |
| **宽高比 0.35 ~ 1.3** | 太瘦长会被游戏拒收 |
| **每张图里只能有一个角色** | 多角色会被拒收 |
| 可用格 | 11 个：idle×2 / walk×4 / attack×3 / hurt×2（网格 16 格里另 5 格留空） |
| 留空没关系 | 必需帧留空会自动用 idle_0 补齐，导出仍合法 |

**植物不移动**，walk 那 4 格可以留空。

## 九、常见问题

### 双击 `开始生成.command` 提示「无法打开，因为来自身份不明的开发者」

macOS 的安全机制。两种解法：

- **右键点它 → 打开 → 在弹窗里点「打开」**（只需做一次）
- 或在终端里执行：

  ```bash
  chmod +x 开始生成.command
  xattr -d com.apple.quarantine 开始生成.command
  ```

### 提示 `没读到 token`

环境变量没设，或者设在了另一个窗口里。重新设一次，注意别漏了引号：

```bash
export MODELSCOPE_TOKEN="ms-xxxx"
```

### 提示 `token 无效或无权限（HTTP 401）`

- 复制时多带了空格或引号
- 用的是登录密码，不是「访问令牌」
- 令牌过期了，去 ModelScope 重新生成一个

### 提示 `没找到任务包`

把 `*_jobs.zip` 放在脚本**同一个文件夹**里，或者在命令行里把路径带上：

```bash
python3 art_studio_cli.py /Users/你/Downloads/ballista_jobs.zip
```

### 生成很慢 / 卡在「等待 N/72」

模型排队。耐心等；连续 6 分钟没响应会超时。

### 网页里点「重抽」提示「连不上」

这是**预期行为**——浏览器不允许直连 ModelScope。
请用「导出生成任务 → 跑脚本 → 导入结果」这条流程。

### 导入结果后图还是旧的

检查 zip 里的文件名是不是 `<角色key>__<帧名>.png`，例如 `ballista__attack_1.png`。
名字对不上就会被跳过（日志里会写「已导入 N 帧」，N 对不对）。

## 附：网页里那几个按钮分别做什么

| 按钮 | 给谁 | 内容 |
|---|---|---|
| **导出工作副本** | 你自己留档 | 完整工作台（含改动和 prompt），双击继续改 |
| **导出生成任务 .zip** | 交给生成脚本 | jobs.json + 参考图 |
| **导入生成结果 .zip** | 从脚本拿回来 | 自动回填到对应帧 |
| **导出资源包 .zip** | 发给开发 | 当前这一个角色的精灵表 |
| **导出全部已改（zip）** | 发给开发 | 所有改过的角色 + workspace.json |
