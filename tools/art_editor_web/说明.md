# 植物立绘工坊 · 使用说明（macOS）

这是一个**离线**的立绘工作台：双击 `index.html` 就能用，
内置游戏现有的 51 个角色（36 株植物 + 15 种僵尸）。

生成图片这一步用附带的 Python 脚本在本机跑——因为 ModelScope
不允许浏览器直连（CORS），网页里点「重抽」一定失败。

---

## 五分钟上手

```
① 双击 index.html（建议用 Chrome / Edge；Safari 也能用但有存储限制，见第七节）
② 左边选一个角色（或「＋新建植物」）
③ 点中间任意一格 → 上方出现这一帧的 prompt，可以改
④ 点「导出生成任务 .zip」→ 下载到 ~/Downloads/xxx_jobs.zip
⑤ 双击「开始生成.command」
   （第一次要先装 Python 和设置令牌，见第二、三节）
⑥ 得到 xxx_results.zip → 回网页点「导入生成结果」
⑦ 满意后点「导出工作副本」留档，点「导出全部已改（zip）」发给开发
```

---

## 一、先确认 Mac 上有 Python 3

打开「终端」（Launchpad 里搜 `终端`，或 Spotlight 搜 `Terminal`），输入：

```bash
python3 --version
```

- 显示 `Python 3.x.x`（x ≥ 8）→ **可以直接跳到第二节**
- 显示 `command not found` 或弹出「需要安装命令行开发者工具」→ 继续往下读

### 安装 Python（三选一）

**方式 A：官网安装包（推荐，最稳）**

1. 打开 <https://www.python.org/downloads/macos/>
2. 点页面上第一个 **Download Python 3.x.x** 按钮（.pkg）
3. 双击下载的 `.pkg`，一路「继续」→「同意」→「安装」
4. 关掉终端窗口，**重新打开一个**，再执行 `python3 --version` 验证

**方式 B：Homebrew（已经装了 brew 的话一条命令）**

```bash
brew install python
```

**方式 C：跟着系统弹窗走**

执行 `python3 --version` 时如果弹出
「需要安装命令行开发者工具 / Command Line Developer Tools」，
点「安装」，等进度条走完，再重新执行 `python3 --version`。

> 脚本只用到 Python 标准库，**不需要 `pip install` 任何东西**。
> 也**不需要** `sudo`。

## 二、设置 ModelScope 令牌

### 1. 拿到令牌

1. 打开 <https://modelscope.cn> 登录
2. 右上角头像 → **个人中心** → 左侧 **访问令牌**（Access Token）
3. 复制形如 `ms-xxxxxxxx-xxxx-xxxx` 的那串

> 这是**密钥**，不要发到群里、不要提交到代码仓库。
> 没有账号或拿不到令牌，直接找对接的开发要。

### 2. 让脚本读到它（三选一，推荐第一种）

**方式 A：用 `.token` 文件（最省事，双击就能跑）**

在工坊文件夹里新建一个纯文本文件，文件名就叫 `.token`，
内容只有一行令牌：

```
ms-你复制的令牌
```

在终端里建也可以（把令牌换成你自己的）：

```bash
cd ~/Downloads/植物立绘工坊
printf '%s' 'ms-你复制的令牌' > .token
```

`开始生成.command` 会自动读它。

**方式 B：临时环境变量（关掉终端就失效）**

```bash
export MODELSCOPE_TOKEN="ms-你复制的令牌"
```

**方式 C：永久写进 shell 配置**

```bash
echo 'export MODELSCOPE_TOKEN="ms-你复制的令牌"' >> ~/.zshrc
source ~/.zshrc
```

## 三、生成图片

### 方式 A：双击（最简单）

双击 **`开始生成.command`**。它会：

- 自动在同目录找 `*_jobs.zip`
- 找不到 Python 会提示你怎么装
- 跑完把 `xxx_results.zip` 放在同一目录

> 第一次双击如果提示「无法打开，来自身份不明的开发者」：
> **右键点它 → 打开 → 在弹窗里点「打开」**（只需一次）。
> 或者先在终端里执行：
>
> ```bash
> cd ~/Downloads/植物立绘工坊
> chmod +x 开始生成.command
> xattr -d com.apple.quarantine 开始生成.command
> ```

### 方式 B：命令行（更灵活）

```bash
cd ~/Downloads/植物立绘工坊

# 先看计划，不花额度（建议第一次先这么跑）
python3 art_studio_cli.py 你的任务包.zip --dry-run

# 真的生成
python3 art_studio_cli.py 你的任务包.zip

# 只重跑某几帧
python3 art_studio_cli.py 你的任务包.zip --only idle_0,attack_1
```

> **耗时**：一帧通常 20~60 秒，11 帧约 5~10 分钟。
> 中途 `Ctrl + C` 可以停，已生成的部分仍会保存。

## 四、导回网页

回到页面，点「**导入生成结果 .zip**」，选 `xxx_results.zip`。

会按文件名 `<角色key>__<帧名>`（例如 `ballista__attack_1.png`）
自动回填到对应格子，日志区显示「已导入 N 帧」。

---

## 五、帧规格

| 项 | 要求 |
|---|---|
| 一帧一张图 | 尺寸不限，页面自动缩放并底部居中 |
| **宽高比 0.35 ~ 1.3** | 太瘦长会被游戏拒收 |
| **每张图只能有一个角色** | 多角色会被拒收 |
| 可用格 | 11 个：idle×2 / walk×4 / attack×3 / hurt×2 |
| 留空没关系 | 必需帧留空会自动用 idle_0 补齐 |

**植物不移动**，walk 那 4 格可以留空。

---

## 六、每帧的 prompt 都存在哪

三处都会存，方便以后追溯每张图的来历：

| 位置 | 存进 |
|---|---|
| 外观描述（左栏②） | 存档记录 `desc` + 导出的 `meta.json` |
| 风格约束（左栏③） | 存档记录 `style` + `meta.json` |
| 每帧 prompt | 存档记录 `framePrompts` + `meta.json` 的 `frame_prompts` |

导出的 `meta.json` 长这样：

```json
{
  "key": "snow_pea",
  "desc": "……整株描述……",
  "style": "……风格约束……",
  "frame_prompts": { "idle_0": "……", "attack_1": "……" }
}
```

---

## 七、怎么保存进度

| 方式 | 说明 |
|---|---|
| **导出工作副本** ⭐ | 下载一个含全部改动（图 + 每帧 prompt）的新 HTML。**下次双击那个新文件就接着改** |
| 自动保存 | Chrome / Edge 会存到本机浏览器；**Safari 双击打开时浏览器会禁用存储**，只靠上面那条 |
| 导出全部已改 | 发给开发：所有改过的角色的精灵表 + `workspace.json` |

**建议习惯**：改完一批就点一次「导出工作副本」，文件名自带时间，等于自动版本管理。

## 八、常见问题

### 双击 `开始生成.command` 提示「无法打开，因为来自身份不明的开发者」

**右键 → 打开 → 弹窗里点「打开」**（只需一次）。

或在终端里：

```bash
cd ~/Downloads/植物立绘工坊
chmod +x 开始生成.command
xattr -d com.apple.quarantine 开始生成.command
```

### 双击后窗口一闪就没了

说明脚本里报错但窗口来不及显示。改成在终端里跑，就能看到完整报错：

```bash
cd ~/Downloads/植物立绘工坊
python3 art_studio_cli.py
```

### 提示 `没读到 token`

`.token` 文件不在脚本同目录，或者内容多了引号/空格。
用这个检查：

```bash
cd ~/Downloads/植物立绘工坊
ls -la .token && cat .token
```

### 提示 `token 无效或无权限（HTTP 401）`

- 复制时多带了空格或引号
- 用的是登录密码，不是「访问令牌」
- 令牌过期了，去 ModelScope 重新建一个

### 提示 `没找到任务包`

把 `*_jobs.zip` 用「导出生成任务」下载到**同一个文件夹**，或者指定路径：

```bash
python3 art_studio_cli.py ~/Downloads/ballista_jobs.zip
```

### 卡在「等待 N/72」

模型在排队。连续 6 分钟没响应会超时，可以 `--only` 单独重跑某一帧。

### 网页里点「重抽」提示「连不上」

这是**预期行为**。浏览器不允许直连 ModelScope，
请走「导出生成任务 → 跑脚本 → 导入结果」。

### 导入结果后图没变

检查 zip 里的文件名是不是 `<角色key>__<帧名>.png`，
名字对不上会被跳过（日志里「已导入 N 帧」的 N 对不对）。

## 九、Windows 上跑（备用）

如果以后要在 Windows 上跑，同样三步：

1. 装 Python：<https://www.python.org/downloads/windows/>，
   安装时**务必勾选 `Add python.exe to PATH`**
2. 设置令牌（PowerShell）：

   ```powershell
   $env:MODELSCOPE_TOKEN = "ms-你复制的令牌"
   ```

3. 运行：

   ```bat
   python art_studio_cli.py 你的任务包.zip
   ```

## 附：网页里那几个按钮分别做什么

| 按钮 | 给谁 | 内容 |
|---|---|---|
| **导出工作副本** | 你自己留档 | 完整工作台（含改动和 prompt），双击继续改 |
| **导出生成任务 .zip** | 交给生成脚本 | jobs.json + 每帧参考图 |
| **导入生成结果 .zip** | 从脚本拿回来 | 自动回填到对应帧 |
| **导出资源包 .zip** | 发给开发 | 当前这一个角色的精灵表 |
| **导出全部已改（zip）** | 发给开发 | 所有改过的角色 + `workspace.json` |
