# 植物立绘工坊

双击 `index.html` 就能用。里面已内置游戏现有的 51 个角色。

生成图片用附带的 `art_studio_cli.py`（只需要 Python，不用装别的库）。

---

## 在 Mac 上

### 1. 打开工坊

双击 `index.html`。建议用 Chrome 或 Edge。

### 2. 改图

- 左边选一个角色（或「＋新建植物」）
- 点中间任意一格 → **上方出现这一帧的 prompt**，可以随便改
- 每帧 prompt 会跟存档一起保存

### 3. 导出任务

点 **「导出生成任务 .zip」**，下载到 `~/Downloads/xxx_jobs.zip`。

把它拖到工坊文件夹里（和 `art_studio_cli.py` 放一起）。

### 4. 跑 Python

```bash
cd ~/Downloads/植物立绘工坊
python3 art_studio_cli.py xxx_jobs.zip --token ms-你的令牌
```

令牌在 <https://modelscope.cn> → 右上角头像 → 个人中心 → **访问令牌**。

先看计划、不花钱：

```bash
python3 art_studio_cli.py xxx_jobs.zip --token ms-xxx --dry-run
```

只重跑某几帧：

```bash
python3 art_studio_cli.py xxx_jobs.zip --token ms-xxx --only idle_0,attack_1
```

跑完得到 `xxx_results.zip`。

### 5. 导回网页

点 **「导入生成结果 .zip」**，选 `xxx_results.zip`，自动回填到对应帧。

### 保存进度

点 **「导出工作副本」** 会下载一个新 HTML，含你改过的全部图和 prompt。
下次双击那个新文件就接着改。

---

## 没有 Python 怎么办

```bash
python3 --version
```

没有输出显示版本号，就去 <https://www.python.org/downloads/macos/>
下 `.pkg` 双击安装，装完**重新开一个终端**再验证。

不需要 `pip install` 任何东西，也不需要 `sudo`。

## 帧规格

| 项 | 要求 |
|---|---|
| 宽高比 | 0.35 ~ 1.3（太瘦长会被游戏拒收） |
| 每张图 | 只能有一个角色 |
| 可用格 | 11 个：idle×2 / walk×4 / attack×3 / hurt×2 |
| 留空 | 必需帧留空会自动用 idle_0 补齐 |

植物不移动，walk 那 4 格可以留空。

---

## 常见问题

**`python3: command not found`**
→ 去 python.org 装，装完重开终端。

**`没找到任务包`**
→ 把 zip 放到脚本同目录，或写完整路径 `python3 art_studio_cli.py ~/Downloads/xxx_jobs.zip --token ...`

**`token 无效或无权限（HTTP 401）`**
→ 复制时带了空格/引号；或用的是登录密码而不是「访问令牌」。

**网页里点「重抽」提示连不上**
→ 预期行为。ModelScope 不允许浏览器直连（CORS），所以生成走脚本。

**导入结果后图没变**
→ zip 里的文件名必须是 `<角色key>__<帧名>.png`，例如 `ballista__attack_1.png`。

**工坊里的存档**
→ Chrome/Edge 会自动存；Safari 双击打开时浏览器禁用存储，
  所以养成「改完点一次导出工作副本」的习惯最稳。
