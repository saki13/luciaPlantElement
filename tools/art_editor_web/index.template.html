③ 保存

最稳的是点下面的「导出工作副本」：下载一个新 HTML， 里面含你改过的全部图。下次双击那个文件即可继续，不依赖浏览器存储。
尚未保存
这是最稳的保存方式：会下载一个新 HTML，里面已经包含你改过的所有图。 下次双击这个新文件就能看到全部改动，继续改完再导出一次。 换电脑、用 Safari、清缓存都不怕。

④ Prompt

⑤ 动作帧 0/11

选中一帧开始编辑

点下面任意一格来选中它。
点任意一格选中它，下方会出现这一帧的 prompt 编辑区和「重抽」按钮。 共 11 个可用格：idle×2 / walk×4 / attack×3 / hurt×2（另 5 格留空）。 留空的必需帧会用 idle_0 自动补齐。

⑦ 合成预览

就绪。图片只在你浏览器里处理，不会上传到任何服务器。

⑦ AI 生成（可选）

ModelScope 默认，Key 填 ms-xxx。
注意：ModelScope 服务端不允许浏览器直连（CORS，已实测）， 直接点会报「连不上」。所以日常请用离线批量：
① 点右下「导出生成任务 .zip」→ 发给开发
② 开发跑完回传结果 zip → 点「导入生成结果」自动回填
如果你自己有代理/中转，也可以把地址填成它，然后在页面里直接生成。
Key 只存本机浏览器，不会进导出包。

离线批量（推荐）

把当前角色要出的帧整理成一个任务包，交给开发批量跑，再把产出的图导回来。 完全不受 CORS 限制。
图生图会以当前帧为参考，保持同一个角色只改姿态—— 这是让 11 帧看起来是同一株植物的关键。
若报 CORS / 网络错误，说明该服务不允许浏览器直连： 把 prompt 复制出来用你自己的工具出图，再拖进格子。
