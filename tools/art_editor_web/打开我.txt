========================================
  在 Mac 上，四步跑起来
========================================

① 双击 index.html
   建议用 Chrome 或 Edge 打开（Safari 会禁用本地存储，见说明.md 第七节）

② 选角色、改 prompt
   左边选一个角色，或点「＋新建植物」
   点中间任意一格 → 上方出现这一帧的 prompt，可以随便改

③ 生成图片
   a. 点右下「导出生成任务 .zip」→ 下载到 ~/Downloads
   b. 把这个 zip 拖进工坊文件夹
   c. 双击「设置令牌.command」，粘贴一次 ModelScope 令牌（ms-xxx）
   d. 双击「开始生成.command」，等它跑完 → 得到 xxx_results.zip
   e. 回网页点「导入生成结果 .zip」→ 自动回填到对应帧

④ 交差
   - 点「导出工作副本」留档：下次双击那个新文件继续改
   - 点「导出全部已改（zip）」发给开发

========================================
  第一次用之前，确认 Mac 有 Python 3
========================================

打开「终端」输入：

    python3 --version

显示 Python 3.x.x 就可以用（x >= 8）。
没有的话去 https://www.python.org/downloads/macos/ 下 .pkg 双击安装，
装完重新打开终端再验证。详细步骤见 说明.md 第一节。

第一次双击 .command 若提示"来自身份不明的开发者"：
右键 → 打开 → 弹窗里点「打开」（只需一次）。

========================================
  为什么生成要跑脚本，不能在网页里点
========================================

ModelScope（Qwen-Image）不允许浏览器直连（CORS），
网页里发请求必然失败。所以生成这一步交给附带的 Python 脚本，
其它所有工作（选角色、改 prompt、看图、保存、导出）都在网页里。

========================================
  存档
========================================

建议养成「改完就点一次『导出工作副本』」的习惯：
它会下载一个含全部改动的新 HTML，下次双击那个新文件就能接着改，
不依赖浏览器存储，Mac / 清缓存 / 换电脑都不怕。
