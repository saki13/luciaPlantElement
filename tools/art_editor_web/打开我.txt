双击 index.html 即可开始。不用安装任何东西（除了生成图片那一步需要 Python）。

========================================
  这里有什么
========================================

index.html          工作台本体，内置 51 个角色的现有立绘
说明.md             ★ 完整说明，含 macOS / Windows 安装 Python 的步骤
art_studio_cli.py   生成图片的脚本（只用到 Python 标准库，不用 pip install）
开始生成.bat        Windows：双击运行生成脚本
开始生成.command    macOS：双击运行生成脚本
打开我.txt          本文件

========================================
  五分钟上手
========================================

① 双击 index.html
② 左边选一个角色（或点「＋新建植物」）
③ 点中间任意一格 → 上方出现这一帧的 prompt，可以改
④ 点右下「导出生成任务 .zip」→ 得到 xxx_jobs.zip
⑤ 双击「开始生成」脚本 → 等它跑完
   第一次用要装 Python，并用环境变量设置 ModelScope 令牌，
   具体步骤见 说明.md 的第二步~第四步
⑥ 得到 xxx_results.zip → 回网页点「导入生成结果」
⑦ 满意后：
   - 点「导出工作副本」留档（下次双击新文件继续改）
   - 点「导出全部已改（zip）」发给开发

========================================
  为什么生成要跑脚本，不能在网页里点
========================================

ModelScope（Qwen-Image）服务端不允许浏览器直连（CORS），
网页里发请求必然失败。所以生成这一步用附带的 Python 脚本完成，
其它所有工作（选角色、改 prompt、看图、保存、导出）都在网页里。

========================================
  存档
========================================

建议养成「改完就点一次『导出工作副本』」的习惯：
它会下载一个含全部改动的新 HTML，下次双击那个新文件就能接着改，
不依赖浏览器存储，Mac / 清缓存 / 换电脑都不怕。
