## 四、结论：明天最该做什么

1. **门户界面**（P0）—— 没有它，玩家连功能都进不去。
2. **工坊 UI**（P0）—— M2 的核心，逻辑已就绪，只差界面。
3. 做完 1+2，M1–M3 的主循环才真正闭合（打关 → 拿代币 → 造植物 → 打更难的关）。

无尽/爬塔 UI、M3 阶段 Boss 可以排在其后；它们不阻塞主循环。

**Godot 全量可玩**需要先补 Bot + 出怪调度，这是一大块独立工作，不建议和 UI 并行。
