## 二、卡槽位（Card Slots）系统 —— 之前整个漏掉了

**问题**：现在关卡卡池是固定的 `M3_POOL_EARLY` / `LATE_POOL`，
玩家"能带几株上场"没有概念。既然要"自己设计植物"，就必须有**卡槽上限**，
否则后期几十株植物全带，关卡难度形同虚设。

### 2.1 提案

| 事件 | 卡槽变化 |
|---|---|
| 初始 | **6 槽** |
| 每个能力挑战关首通（M2 共 6 关） | **+1**（共 +6） |
| 每进入新阶段（P2 / P3 / P4） | **+1**（共 +3） |
| 上限 | **15** |

换算：M2 打完 6+6+1 = 13 槽；进 M4 = 15 槽（封顶）。

### 2.2 与现有代码的关系（待确认）

- 现在每关的卡池是**写死的一串 key**。改成：
  `可带 = min(卡槽数, 已解锁植物)`，关卡只限制"哪些植物本关可用"（标签/品阶）。
- 需要新增 `PlayerProgress.card_slots`，并进存档。
- 关卡 JSON 增加 `pool_mode: "unlocked"` 与 `unlock_upto`。

**待确认**：初始 6 槽是否太少？原版是 6–10 槽随进度涨，6 起步是合理的。

## 三、抛射僵尸（远程压制后排）

**目的**：让"玻璃大炮放后排"不再是绝对安全，逼玩家造**治疗植物**或**反制手段**。

### 3.1 行为

| 项 | 值（待确认） |
|---|---|
| 名字 | 抛射僵尸 `lobber` |
| 血量 | 800 |
| 速度 | 慢（= 普通僵尸的 60%） |
| 停步距离 | 距最前排植物 **3 格**停下 |
| 抛射间隔 | 2.5s |
| 抛射伤害 | 100（**无视前排阻挡与格挡**） |
| 落点 | 该行**最靠后的植物**（即后排） |
| 韧性 | 档 2（50） |

### 3.2 为什么这样设计

- 它**不啃前排**，直接越过防线打后排 → 后排的西瓜、投手这类脆皮被迫要保护。
- **不能靠堆肉盾解决**（肉盾在前排，它不打前排）→ 逼出"治疗""速杀""分散站位"。
- 与"抛射弹"呼应：玩家的卷心菜投手也是抛射，**双方都有抛射**，对称。

### 3.3 反制手段（需要在设计上给足）

| 反制 | 说明 |
|---|---|
| **治疗植物** | 你要求的核心解法：范围治疗撑住后排血量 |
| 速杀 | 它血 800 不算厚，高 DPS 可以强杀 |
| 分散站位 | 后排不留关键植物在同一列 |
| 未来的伞叶 | 原版有"伞叶"挡抛射，可作为后续扩展 |

> **待确认**：抛射伤害 100 对后排（多为 300 HP 的 1 档坦度）意味着 3 发打死。
> 这个节奏对吗？还是应该 200（2 发）制造更紧迫的压力？

## 四、亵渎光环（全屏持续削血）

**目的**：惩罚"龟缩拖时间"，逼玩家主动清场；同时给治疗植物第二条存在理由。

### 4.1 行为

| 项 | 值（待确认） |
|---|---|
| 持有者 | 精英僵尸 / Boss 的被动光环 |
| 效果 | **每秒扣除全场所有植物 1.5% 最大生命** |
| 范围 | **全屏**（不按行列） |
| 叠加 | 同时最多 **2 层**（两只同类不叠到 4 层） |
| 韧性 | 档 4（105） |

### 4.2 为什么是百分比

- 固定值（如 5 HP/s）对高血量植物是挠痒，对低血量植物是秒杀；
- **百分比**对所有植物一视同仁，且天然惩罚"堆肉盾拖时间"。
- 1.5%/s → 约 **67 秒清空满血植物**，足够玩家反应但不至于无解。

### 4.3 反制

| 反制 | 说明 |
|---|---|
| **速杀持有者** | 最直接，符合"斩首"直觉 |
| **治疗植物** | 治疗量 > 1.5% 最大生命/秒即可抵消 |
| 减少上场植物 | 少放就少亏，逼迫玩家精算卡槽 |

> **这是对"卡槽位系统"的完美互补**：光环逼你少带，抛射逼你带治疗。

## 五、这四项之间的关系（为什么一起做）

```
卡槽位  ── 限制"带多少"
   │
   ├── 抛射僵尸 ── 惩罚"后排玻璃大炮" ── 逼出「治疗植物」
   │
   └── 亵渎光环 ── 惩罚"多带/龟缩"     ── 逼出「少带 + 速杀」
```

四条一起上，玩家的配装才有真正的取舍：
**带治疗就少带输出；带输出就扛不住削血；带多了被光环罚，带少了被抛射打穿后排。**
